# Писалка · GRBL

Адаптация [writing-plotter](https://github.com/IKuschke/writing-plotter). Исходная лицензия и её уведомление сохранены в LICENSE. Оба SVG-шрифта взяты из каталога fonts исходного проекта.

Введите текст, выберите шрифт и скачайте файл NC. Предпросмотр показывает траектории пера. Для поворота в NC используйте настройку «Поворот станка».

## Шрифты

В меню «Почерк» доступны SVG-шрифты из предоставленной коллекции strokefontdata, включая Hershey Cyrillic и Hershey Script. Лицензионный файл коллекции лежит в fonts/stroke/OFL.txt. Выбирайте «Загрузить SVG», чтобы добавить собственные SVG-шрифты, например MADE Likes Script. Загруженные таким способом шрифты хранятся в текущем браузере. Для отсутствующих знаков используется встроенный шрифт.

## Графики, примеры и Word

«Графики и примеры» открывает отдельный редактор с предпросмотром и своим экспортом NC. Он поддерживает графики простых функций, столбчатые диаграммы, блоки с номерами и последовательность вычислений арифметического примера. «Импорт DOCX» добавляет текст, таблицы и встроенные растровые изображения. Изображения обводятся по контрастным границам. Сложная вёрстка, редактируемые диаграммы и формулы Word разбираются частично: форматирование ячеек и формул не переносится, а формулы читаются как линейный текст.
