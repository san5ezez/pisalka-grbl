# Писалка · GRBL

Адаптация [writing-plotter](https://github.com/IKuschke/writing-plotter). Исходная лицензия и её уведомление сохранены в LICENSE. Оба SVG-шрифта взяты из каталога fonts исходного проекта.

Для прямой отправки нужен Chrome или Edge на компьютере и HTTPS. Откройте страницу в обычной вкладке, освободите COM-порт, подключите USB и убедитесь, что вы выставили рабочий ноль. Точная область движения указана рядом с переключателем поворота. Скорость USB 115200. Экспорт NC доступен независимо от подключения.
